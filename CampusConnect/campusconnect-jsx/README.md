# CampusConnect (JavaScript / JSX)

Plain JavaScript version of CampusConnect — all source is `.js` / `.jsx`, no TypeScript.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:8080

## Stack
- React 19 + TanStack Start / Router (file-based routes in `src/routes`)
- Tailwind CSS v4 (`src/styles.css`) with the glassmorphic blue/white design system
- shadcn-style UI components in `src/components/ui`
- Mock data + client state in `src/lib/campus-data.js` and `src/lib/campus-store.jsx`
